1 Overview

The iSEE package provides a general and flexible framework for interactively exploring SummarizedExperiment objects. However, in many cases, more specialized panels are required for effective visualization of specific data types. The altSEE package implements dedicated panel classes to visualise data from altExps in the SingleCellExperiment object that work directly in the iSEE application and can smoothly interact with other panels. This allows users to quickly parametrize bespoke apps for their data to address scientific questions of interest that involves data in the mainExp and altExps. We first load in the package:

library("iSEEu")
library("altSEE")
library("msqrob2")
library("SingleCellExperiment")
library("scater")
library("BiocFileCache")

2 Differential abundance plots

To demonstrate the use of these panels we will perform a differential abundance analysis on the Shen data containing 5 spike-in conditions (a, b, c, d and e) PRIDE identifierPXD003881 (Shen et al. 2018). The data is used in the first chapter of our msqrob2book. Here we will only use spike-in conditions (a-c) for illustration purposes.

We will now perform the data processing and as in msqrob2 vignette in the msqrob2book.

  1. Replace missing values by NA.
  2. Perform log2-transformation
  3. Peptide filtering
  4. Normalisation
  5. Summarization to protein level
qf <- zeroIsNA(qf, "peptides") # 1. convert 0 to NA

qf <- logTransform(qf, base = 2, i = "peptides", name = "peptides_log") # 2.

qf <- filterFeatures(
qf, ~ Proteins != "" & ## 3. Remove failed protein inference
  !grepl(";", Proteins)) ##  3. Remove protein groups
qf <- filterFeatures(qf, ~ Reverse != "+" & ## 3. Remove decoys
                          Potential.contaminant != "+") ## 3. Remove contaminants
qf <- filterNA(qf, i = "peptides_log", pNA = .67) ## 3. Remove peptides that were picked up in less than 4 samples: pNA = 1-4/12. 

qf <- sweep( #Subtract log2 norm factor column-by-column (MARGIN = 2) 
  qf,
  MARGIN = 2,
  STATS = nfLogMedian(qf,"peptides_log"),
  i = "peptides_log",
  name = "peptides_norm"
) ## 4. Normalisation

qf <- aggregateFeatures(qf,
    i = "peptides_norm", 
    fcol = "Proteins", 
    na.rm = TRUE,
    name = "proteins"
) ## 5. summarisation to protein level

We model the data using msqrob2 and infer differential expression for all pairwise comparisons.

model <- ~ condition
qf <- msqrob(
    qf,  
    i = "proteins",
    formula = model,
    robust = TRUE)

(allHypotheses <- createPairwiseContrasts(
  model, 
  colData(qf), 
  "condition"
))
## [1] "conditionb = 0"              "conditionc = 0"             
## [3] "conditionc - conditionb = 0"
(L <- makeContrast(
  allHypotheses,
  parameterNames = 
    model.matrix(model, colData(qf)) |>
    colnames())
)
##             conditionb conditionc conditionc - conditionb
## (Intercept)          0          0                       0
## conditionb           1          0                      -1
## conditionc           0          1                       1
#Rename columns L
colnames(L) <- c("b-a","c-a","c-b")

qf <- hypothesisTest(
  qf,
  i = "proteins",
  contrast = L)

Convert QFeatures object to SingleCellExperiment

sce <- getWithColData(qf, i ="proteins") |> 
   as("SingleCellExperiment")
rn <- rowData(sce) |> names()
rowData(sce) <- rowData(sce)[,rn!="msqrobModels"] |> as.data.frame() 
assayNames(sce) <- c("proteins","aggcounts")

Add reduced dim plot

sce <- sce |> 
  runMDS(exprs_values = 1)

Add altExps with peptide dat

altExp(sce,"peptides") <- qf[["peptides_norm"]]
assayNames(altExp(sce,"peptides")) <-"peptides_norm"

assay(altExp(sce,"peptides"),"peptides_log") <- assay(qf,"peptides_log")

2.1 launch iSEE

shenAltExpApp <- iSEE(
  sce,
  initial = list(
    ReducedDimensionPlot(),
    VolcanoPlot(),
    RowDataTable(RowSelectionSource = "VolcanoPlot1"),
    MainExpPlot(YAxisFeatureSource = "RowDataTable1", 
                 PlotType = "Scatter + lines", 
                 XAxis = "Column data",
                 XAxisColumnData = "sampleId"),
    AltExpPlot(YAxisFeatureSource = "RowDataTable1", 
                AltAssay = "peptides_norm",
                PlotType = "Scatter + lines", 
                XAxis = "Column data", 
                XAxisColumnData = "sampleId")
  )
)

To launch the app you can just enter its name cptacAltExpApp on the command line.

shenAltExpApp

Note that you can adjust the volcano plot for other contrasts e.g. c-a and c-b by selecting the corresponding p-value and log2 fold changes in the volcano plot.
